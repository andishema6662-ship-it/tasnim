# صوتی

پخش‌کنندهٔ خواندن بلند برای خبرهای فارسی. دو بخش دارد:

- افزونهٔ وردپرس که روی نوشتهٔ تکی، بالای متن، پخش‌کننده می‌گذارد.
- یک اسکریپت جاسازی بدون وابستگی، برای هر سایت دیگری.

دکمه‌ها: پخش، مکث، توقف، سرعت، و انتخاب صدا بین منیژه و بیژن.

## نصب در وردپرس

ریشهٔ این مخزن خود افزونه است و فایل اصلی `soti.php` است.

1. پوشه را در `wp-content/plugins/soti` کپی کنید. اگر مخزن را مستقیم کلون می‌کنید، همان پوشه کافی است.
2. از پیشخوان وردپرس افزونهٔ «صوتی» را فعال کنید.
3. یک نوشتهٔ تکی را در سایت باز کنید. پخش‌کننده بالای متن همان نوشته دیده می‌شود.

اسکریپت و سبک فقط در نوشتهٔ تکی (`is_singular('post')`) بارگذاری می‌شوند. در فهرست، برگه، خوراک و درخواست JSON پخش‌کننده اضافه نمی‌شود.

خروجی با توابع وردپرس ساخته می‌شود و کلید سرویس ابری هرگز در صفحه چاپ نمی‌شود.

## جاسازی در سایت دیگر

کنار `soti.js` باید فایل `soti.css` هم باشد. اسکریپت، سبک را خودش کنار فایل جاوااسکریپت پیدا می‌کند.

```html
<script src="assets/soti.js" data-selector=".news-body" defer></script>
```

`data-selector` سلکتور CSS بدنهٔ مقاله است. اگر آن را ننویسید، اسکریپت به ترتیب این‌ها را امتحان می‌کند:

`[data-soti-article]`، `.soti-article`، `article .entry-content`، `.entry-content`، `.post-content`، `.article-body`، `.article__body`، `.article__content`، `[itemprop="articleBody"]`، `article`، `main`

برای یک قالب مشخص، سلکتور را روی همان عنصری بگذارید که فقط متن خبر داخلش است. مثلاً:

```html
<script src="assets/soti.js" data-selector="article .entry-content" defer></script>
```

## نمونهٔ محلی

فایل `embed/demo.html` یک خبر فارسی ساختگی است، با ناوبری، تبلیغ، خبر مرتبط و دیدگاه، تا معلوم باشد این‌ها خوانده نمی‌شوند.

بعضی مرورگرها روی نشانی `file://` گفتار را می‌بندند. صفحه را با یک سرور محلی باز کنید:

```bash
python3 -m http.server 8765
```

بعد بروید به `http://localhost:8765/embed/demo.html`.

## کنترل‌ها

- پخش، مکث، توقف
- سرعت: ۰٫۷۵×، ۱×، و ۱٫۲۵×. پیش‌فرض ۱ است. نرخ بالاتر از ۱٫۲۵ به ۱٫۲۵ برمی‌گردد.
- صدا: منیژه (زن) و بیژن (مرد). پیش‌فرض منیژه است.

اگر هنگام پخش سرعت را عوض کنید، همان تکه از نو با سرعت جدید خوانده می‌شود تا تغییر همان لحظه شنیده شود. اگر پخش مکث باشد، سرعت تازه از تکهٔ بعدی اعمال می‌شود. نرخ از آداپتر عبور می‌کند: در موتور داخل صفحه، `playbackRate` وب‌آدیو (از ۰٫۷۵ تا ۱٫۲۵)، در گفتار مرورگر `utterance.rate`، در بک‌اند اختیاری eSpeak سرعت `۱۷۵ × نرخ` (بین ۸۰ و ۴۵۰)، و در پروکسی آژور فیلد `rate`.

نوار پیشرفت نشان می‌دهد خواندن در کدام بخش از متن است.

## صداها

دکمه‌های منیژه و بیژن فقط برچسب انتخاب کاربرند. صدای اختصاصی نرم‌افزار نشان، فایل صوتی‌اش، مدلش و کدش در این پروژه نیست و بازتوزیع نمی‌شود.

نمونه‌ای که منتشر شده با فایل‌های ازپیش‌ساختهٔ Piper پخش می‌شود. بازدیدکننده مدل را دانلود نمی‌کند و eSpeak صدا را نمی‌سازد. سرعت، از ۰٫۷۵× تا ۱٫۲۵×، نرخ پخش Web Audio همان فایل است.

- منیژه: Piper `fa_IR-mana-medium`، صدای زن دادگان Mana-TTS.
- بیژن: Piper `fa_IR-amir-medium`، صدای مرد امیر.
- اگر فایل همان تکه موجود نباشد، پیام «صدای فارسی در این مرورگر پیدا نشد.» دیده می‌شود.
- کیفیت ماشینی است و ضبط انسان نیست. مدل عصبی Piper به‌خاطر حجم چندده‌مگابایتی بسته نشده.

متن بلند تکه‌تکه می‌شود و تکه‌ها به ترتیب پخش می‌شوند. در اولین تکه، وضعیت «در حال آماده‌سازی صدا» است تا فایل موتور برسد.

اگر مرورگر Web Audio نداشته باشد، و نشانی پروکسی آژور هم نباشد، پخش‌کننده به Web Speech API برمی‌گردد و فقط وقتی حرف می‌زند که صدای `fa-IR` واقعاً نصب باشد (مثل Dilara برای منیژه و Farid برای بیژن). Chrome معمولاً این صدای سیستمی را دارد؛ فایرفاکس و سافاری اغلب ندارند. اگر هیچ موتوری نماند، همان پیام فارسی نشان داده می‌شود.

### بک‌اند اختیاری eSpeak

اگر خودتان بک‌اند eSpeak را دارید، قبل از اسکریپت بگذارید. این بک‌اند بر موتور داخل بسته مقدم است:

```html
<script>
  window.SOTI_ESPEAK_BACKEND = myEspeakBackend;
</script>
<script src="assets/soti.js" data-selector=".news-body"></script>
```

`myEspeakBackend.speak(text, { voice, speed, rate })` باید قولی برگرداند که با پایان پخش حل شود. `voice` یکی از `fa+f2` یا `fa+m3` است و `speed` برابر `۱۷۵ × نرخ` است. اگر این بک‌اند را نگذارید، همان eSpeak داخل `assets/vendor` حرف می‌زند.

### آداپتر ابری، بدون کلید و بدون تماس

اگر پروکسی خودتان را به Azure AI Speech وصل کنید، نگاشت این است:

- منیژه → `fa-IR-DilaraNeural` (زن)
- بیژن → `fa-IR-FaridNeural` (مرد)

افزونه مستقیم به مایکروسافت درخواست نمی‌زند و کلیدی داخل صفحه نمی‌گذارد. پروکسی باید کلید را سمت سرور نگه دارد، بدنهٔ JSON را بگیرد و فایل صوتی برگرداند:

```json
{ "text": "…", "voice": "fa-IR-DilaraNeural", "rate": 1.25, "lang": "fa-IR" }
```

در وردپرس فقط نشانی پروکسی را بدهید:

```php
add_filter('soti_config', function ($config) {
    $config['azure_endpoint'] = 'https://example.com/soti-azure-proxy';
    return $config;
});
```

بدون این نشانی هیچ تماسی گرفته نمی‌شود. نرخ `rate` همان سرعت پخش‌کننده است (از ۰٫۷۵ تا ۱٫۲۵) تا پروکسی آن را به `prosody` آژور بدهد.
