# سامانه مدیریت و رزرو اردوگاه‌ها

یک وب‌اپلیکیشن برای مدیریت ظرفیت و رزرو اردوگاه‌های آموزشی، بر اساس «طرح تحلیل موجودیت‌ها». رابط کاربری فارسی (راست‌به‌چپ) و بک‌اند مبتنی بر Express.

A capacity-management and reservation web app for educational camps, based on the project specification. Persian (RTL) UI with an Express backend.

## مدل دامنه

- **اردوگاه‌ها**: مجتمع سیدالشهدا(ع) آبعلی و مجتمع شهدای دانشجو مشهد.
- **منابع** با سه واحد رزرو متفاوت (مطابق نکتهٔ فنی طرح):
  - **اتاق / سوئیت** → رزرو بر اساس **شب** (ظرفیت به تخت).
  - **کلاس / سالن اجلاس / آمفی‌تئاتر / استخر** → رزرو **انحصاری** بر اساس **سانس** (تایم‌اسلات).
  - **سالن غذاخوری** → رزرو بر اساس **وعده** (صبحانه/ناهار/شام/میان‌وعده) با ظرفیت نفر.
- **کاربران و سطوح دسترسی**، **تخفیف‌ها** (فرماندهی ۵۰٪، معاون اردوئی ۴۰٪، بسیج ۳۰٪، سپاه ۲۰٪)، و **مالیات بر ارزش افزوده ۹٪**.

## ماژول‌های اصلی

1. **مدیریت ظرفیت و جلوگیری از تداخل**: بررسی هم‌پوشانی بازه‌ها برای اتاق‌ها، رزرو انحصاری سانس برای سالن‌ها، و ظرفیت وعده‌ای برای غذاخوری.
2. **درخواست دوره (بسته)**: ترکیب اقامت + خدمات (کلاس/سالن) + وعده‌های غذایی در یک درخواست و تولید **پیش‌فاکتور**.
3. **مالی و صدور فاکتور**: محاسبهٔ خودکار (شب × قیمت اتاق) + خدمات + سالن، اعمال تخفیف و مالیات، و چرخهٔ وضعیت `در انتظار → تاییدشده → پرداخت‌شده` (یا `رد`).

## راه‌اندازی

```bash
npm install
npm start        # http://localhost:3000
npm run dev      # حالت توسعه با ری‌استارت خودکار
npm test         # تست‌های خودکار
```

پیش‌نیاز: Node.js نسخهٔ ۲۰ یا بالاتر.

## ساختار پروژه

```
src/
  data.js     # داده‌های اردوگاه‌ها، منابع، نقش‌ها، تخفیف‌ها، تایم‌اسلات‌ها و وعده‌ها (از روی طرح)
  store.js    # ذخیره‌سازی درخواست‌ها/رزروها در فایل JSON
  engine.js   # موتور ظرفیت/تداخل + محاسبهٔ قیمت و فاکتور (شب/سانس/وعده)
  server.js   # سرور Express و مسیرهای API
public/
  index.html  # صفحهٔ اصلی (مرورگر منابع + سازندهٔ دوره + پیش‌فاکتورها)
  styles.css  # استایل تم تیره و راست‌به‌چپ
  app.js      # منطق سمت کاربر
test/
  api.test.js # تست‌های موتور و API با node:test
```

## API

| متد | مسیر | توضیح |
| --- | --- | --- |
| GET | `/api/health` | بررسی سلامت |
| GET | `/api/meta` | نقش‌ها، تخفیف‌ها، وعده‌ها، تایم‌اسلات‌ها، نرخ مالیات |
| GET | `/api/camps` | فهرست اردوگاه‌ها |
| GET | `/api/resources?campId=&type=` | فهرست منابع (با فیلتر) |
| GET | `/api/resources/:id` | جزئیات یک منبع |
| POST | `/api/availability` | بررسی موجودی یک آیتم (شب/سانس/وعده) |
| POST | `/api/invoice/preview` | محاسبهٔ پیش‌فاکتور بدون ذخیره |
| GET | `/api/requests` | فهرست درخواست‌ها/پیش‌فاکتورها |
| POST | `/api/requests` | ثبت درخواست دوره |
| POST | `/api/requests/:id/approve` | تایید مدیر |
| POST | `/api/requests/:id/reject` | رد درخواست |
| POST | `/api/requests/:id/pay` | ثبت پرداخت |

## معماری و توسعهٔ آینده

طرح، معماری تولیدی مبتنی بر PostgreSQL و Django/Node.js و React/Vue را پیشنهاد داده است. این نسخه همان دامنه و ماژول‌ها را روی پشتهٔ سبک Node/Express + ذخیرهٔ JSON پیاده کرده تا به‌سادگی قابل اجرا و نمایش باشد؛ جایگزینی لایهٔ ذخیره‌سازی با PostgreSQL و افزودن درگاه پرداخت و خروجی PDF فاکتور، گام‌های بعدی هستند.

## محیط Cloud Agent

`.cursor/environment.json` وابستگی‌ها را با `npm install` نصب می‌کند و سرور را در ترمینال `web-server` روی پورت ۳۰۰۰ اجرا می‌کند.
