# اتاق خبر

پنل فارسی و راست‌به‌چپ برای تولید، ویرایش، بازبینی و انتشار خبر. داده در `localStorage` مرورگر می‌ماند.

## اجرا

```bash
npm install
npm run dev
```

سپس در مرورگر به [http://localhost:3000](http://localhost:3000) بروید.

نقش را از نوار بالا عوض کنید: خبرنگار پیش‌نویس می‌فرستد، سردبیر بازبینی می‌کند، مدیر مسئول منتشر می‌کند.
